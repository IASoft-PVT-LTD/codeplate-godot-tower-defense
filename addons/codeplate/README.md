# CodePlate add-on

Shared tools for CodePlate Godot templates. Don't edit these files in a project: they're replaced when the template updates. Put project-specific checks in `res://checks/tests/` and screenshot setup in `res://tools/screenshot_hooks.gd`.

| File | What it does |
|---|---|
| `checks/run.gd` | The check runner: `godot --headless --path . --script res://addons/codeplate/checks/run.gd [-- filter]`. Ends with `CODEPLATE CHECKS: PASS` or `FAIL`. |
| `checks/check_case.gd` | `CheckCase`, the base class for checks: `expect`, `expect_eq`, `frames`, `until`, `mouse_button`, `mouse_drag_to`, `action`. |
| `checks/builtin/test_codeplate_project.gd` | Project-wide checks: `assets.json` against the files and its licences (`CodePlate-original` credits CodePlate, the user's own files are `user-owned` and credit their owner, a placeholder or stand-in has `"placeholder": true`), every `res://` path exists, every preset in `export_presets.cfg` includes the data files (JSON, text, CSV, Markdown) the game reads at runtime and leaves out `export/*` and `shots/*`, `export/` and `shots/` each hold an empty `.gdignore`, a Web preset is single-threaded, the save folder has a fixed name (`config/use_custom_user_dir`, `config/custom_user_dir_name`), and an Android preset's `package/name` matches `config/name`. |
| `checks/builtin/test_codeplate_settings.gd` | The settings screen with a stand-in `Game`: `add_row`, the language row, and that every button fits a 1280×720 view. |
| `tools/screenshot.gd` | Screenshots for agents. Run without `--headless`. Customised by `res://tools/screenshot_hooks.gd`. |
| `ui/settings_screen.gd` | `CodePlateSettings`, the settings + credits overlay games open from their title screen: music and effects volume, fullscreen, reset progress (with a confirmation), and a Credits page built from `res://CREDITS.md` (HTML comments hidden). It talks to the `Game` autoload by name: `music_volume`, `sfx_volume`, `fullscreen`, their `set_*()` functions, `save_settings()` and `reset_progress()`; a missing one hides its control. `CodePlateSettings.open(title_screen)` adds it; pass `true` as a second argument for all-caps text. **To add a setting, use `add_row(control)`** on the screen `open()` returns: it goes above Credits (or above the control you name). With `languages` (code → name shown, two or more), `language` and `set_language(code)` on `Game`, it shows a language row. On a view under 800 px tall, Fullscreen, Credits and Reset share a row. Its words go through Godot's translation server, so a project's translation table can translate them. Under the CodePlate Free License the page always shows "Built with CodePlate (codeplate.io)". Exports must include `CREDITS.md` and `LICENSE.md` (`include_filter`). |

**Finding Godot:** CodePlate's tools and the briefs look for the binary in this order: the `GODOT` environment variable, then PATH (`where godot*`, `which godot godot4`), then the usual install folders. On Windows use the `_console.exe` build, which prints output.
